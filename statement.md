# Project Statement

## Problem Statement

Managing student academic records manually can make it difficult to maintain student information, marks, attendance, and performance records in an organized way.

A simple system is required to store student data, manage academic marks and attendance, calculate performance indicators, and provide useful reports.

The Student Performance Management System addresses this problem through a Java-based console application that organizes student records and provides automated performance calculations and reporting.

## Scope of the Project

The project focuses on managing student academic information through a command-line application.

The system includes:

* Student record management
* Marks management
* Attendance management
* Individual performance reporting
* Class-level performance analytics
* Local file-based data storage
* Input validation and error handling

The project is designed for small-scale academic use and uses a local text file instead of a database to keep the implementation simple and suitable for a Java console application.

## Target Users

The intended users are:

* Teachers
* Faculty members
* Academic coordinators
* Students for viewing performance information
* Small educational institutions requiring a lightweight academic record system

## High-Level Features

### 1. Student Management

Users can add, view, search, update, and delete student records.

### 2. Marks and Performance

Users can enter marks for three subjects and the system automatically calculates total marks, average marks, and grade.

### 3. Attendance Management

Users can record attendance and the system calculates attendance percentage and eligibility status.

### 4. Reporting

The system generates individual student performance reports.

### 5. Dashboard

The system provides class-level statistics including average performance, highest-performing student, attendance statistics, and performance categories.

### 6. Data Persistence

Student information, marks, and attendance are stored in a local text file and loaded when the application starts.

## Project Objective

The primary objective is to develop a modular Java application that demonstrates object-oriented programming, collections, file handling, input validation, exception handling, and basic data analysis in a practical academic scenario.
